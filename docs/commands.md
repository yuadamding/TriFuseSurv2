# Command Examples

The original ad hoc command examples were moved out of the code package.

- Legacy scratch examples remain in `docs/commands_examples.md`.
- The stage-oriented workflow overview lives in `docs/pipeline.md`.
- Prefer the installed console scripts from `README.md` for day-to-day usage.
- The authoritative packaged source now lives under `src/trifusesurv/`, organized by `preprocessing/`, `segmentation/`, `multimodal_survival/`, `models/`, and `utils/`.
- `src/trifusesurv/cli/` and the root-level `* 2.py` files are compatibility layers for older entry paths.
